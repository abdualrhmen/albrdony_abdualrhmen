# البردوني (مجموع القصائد)

هذا المستودع يحتوي على مجموعة من قصائد الشاعر البردوني، مُجمّعة للعرض أو التحليل.

الوصف
- هدف المشروع: تخزين وعرض وتحليل نصوص القصائد.
- الحالة: قد تحتاج إلى تحديث حسب تقدم العمل.

كيفية الاستخدام
1. استنساخ المستودع:
```bash
git clone https://github.com/abdualrhmen/albrdony_abdualrhmen.git
cd albrdony_abdualrhmen
```
2. ابحث في مجلديّ `poems/` أو `texts/` لملفات القصائد (إن وُجدت).

المساهمة
- لاقتراح إضافة أو تعديل، افتح Issue أو أرسل Pull Request مع وصف التغيير.

الترخيص
- أضف نوع الرخصة هنا (مثلاً MIT) أو حدّد أن المستودع خاص.
